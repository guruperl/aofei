# 广告主与代理商使用手册

本手册面向通过 W8M 投放广告的广告主，以及受托查看或审核广告主、广告活动和广告组的代理商。内容包括账户职责、投放流程、广告素材与定向、计量口径、外部需求方竞价接入和常见问题。平台地址、账户启用、商务规则和生产接入信息由平台运营方另行提供。

## 1. 账户与职责

系统使用以下与投放有关的角色：

| 角色 | 主要职责 |
|---|---|
| 广告主（`adv`） | 维护自己的账户、广告活动、广告组、广告素材、定向、预算、付款记录和竞价端点。 |
| 代理商（`agent`） | 受托查看广告主、广告活动和广告组，并执行被授权的审核流程。 |
| 平台运营人员（`admin`） | 管理账户状态、竞价端点凭据与启用、外部需求方路由、流量分配和结算视图。 |

代理商账户不是另一个广告主账户，也不自动取得广告主的全部编辑权限。需要创建广告素材、定向或竞价端点时，应由对应广告主账户操作；需要审批、启用、凭据或路由变更时，应联系平台运营人员。

登录地址以运营方提供的域名为准。广告主页面位于：

```text
https://<平台域名>/goto/adv/g/...
```

代理商页面位于：

```text
https://<平台域名>/goto/agent/g/...
```

如果现有密码无法登录，请使用登录页的“忘记密码”功能，或联系平台运营方确认账户状态。

## 2. 投放对象的层级

常规本地投放按以下层级组织：

```text
广告主账户
└── 广告活动（Campaign）
    └── 广告组（Ad Group，系统内部对象名为 Item）
        └── 广告素材（Creative）
```

- 广告活动定义名称、投放时间、流量范围、活动级预算和启用状态。
- 广告组定义价格、计费方式、落地页、频次控制、广告组预算、媒体与流量条件。
- 广告素材定义尺寸、媒体类型、内容、权重和启用状态。
- 定向条件附着在广告组上；广告主、广告活动和广告组还可以共同决定流量方、网站/App 及行业的允许或屏蔽范围。

一个请求只有在账户、广告活动、广告组、广告素材、时间、预算、尺寸、定向和供应侧规则都允许时，才可能参与竞价。仅把最下层广告素材设为启用，并不能绕过上层状态或规则。

## 3. 推荐投放流程

### 3.1 检查账户资料

登录后先检查账户名称、联系人、地址和密码。仪表盘可显示主要广告组和广告位表现。余额、付款及账户启用状态以平台运营规则为准；不要把页面中显示的“已保存”理解为一定已经具备投放资格。

### 3.2 创建广告活动

进入“广告活动”，选择新建并填写：

- 活动名称和可选的外部业务编号；
- 开始与结束时间；
- 说明、目标类型和流量范围（白名单/黑名单）；
- 总预算和每日预算；
- 启用状态。

时间区间、预算和流量范围会影响所有下属广告组。建议先保存为未启用状态，完成广告组、广告素材和定向检查后再启用。

### 3.3 创建广告组

在广告活动下创建广告组，至少检查以下内容：

- 广告组名称；
- 计费方式和价格；
- 落地页；
- 开始与结束时间；
- 总预算与每日预算；
- 展示次数、展示周期和最小展示间隔；
- 点击次数与点击周期；
- 语言、设备、位置、MIME、素材特征及行业规则；
- 启用状态。

当前实时竞价价格以 USD eCPM 参与比较。上游底价为空或为 `USD` 时可参与；系统不做其他币种换算，其他币种的底价会使该广告位不出价。因此，价格和商务结算单位应在上线前与运营方确认。

频次控制依赖可识别的用户或设备。系统依次优先使用买方用户 ID、用户 ID、IFA/设备 ID，最后才可能使用 IP 与 User-Agent 的组合。缺少稳定身份时，跨请求频控效果会受限。

### 3.4 添加素材

在广告组下添加广告素材，并填写素材名称、尺寸、媒体类型、内容、权重和启用状态。素材尺寸必须与目标广告位的配置一致。

当前渲染规则包括：

- 原生和原生视频素材会带有 DSP 展示跟踪，并以 DSP 点击跳转地址作为主链接；
- Banner iframe 会带有 DSP 展示像素；
- Banner 若要使用 DSP 点击测量，素材内容 URL 或模板必须显式使用 `{CLICK_URL}`；
- `{LANDING_URL}` 表示直接的广告主落地页；
- 系统不会重写任意第三方 iframe 或 HTML 内部的点击链接。

因此，上线前应在测试环境实际点击素材并检查最终跳转。不要手工修改系统生成的 `/imp`、`/clk`、`sig` 或 `sig_ts` 参数；修改、过期或未签名的测量地址会被拒绝。

### 3.5 配置定向

广告组可组合以下定向类型：

- 地理：国家、州/省、城市、DMA、ISP、邮编、经纬度和连接类型；
- 人群：性别、年龄/出生年份区间和语言；
- 设备：操作系统、版本、浏览器/平台和设备类型；
- 时间：日期、小时、星期和时区；
- 供应与内容：流量方、网站/App、广告位、行业及流量范围；
- 上传人群：广告主上传的用户或设备标识集合。

空的普通定向通常表示不限。上传人群的语义更严格：配置了多个上传标识类型时，请求必须同时包含并命中每个已配置类型。并且，只要有候选广告组命中上传人群，系统会优先在这一组候选中选择，而不会再把普通组合定向候选放回同一次选择。

建议先用较宽规则完成小流量验证，再逐项收紧；发生无投放时，按“状态与时间 → 预算 → 尺寸 → 供应侧流量范围 → 人群定向”的顺序排查。

### 3.6 上线检查

提交上线或请求运营方协助前，逐项确认：

- 广告主、广告活动、广告组和至少一个广告素材均处于可投放状态；
- 当前时间位于广告活动和广告组的投放区间；
- 总预算和每日预算未耗尽；
- 素材尺寸与目标广告位一致；
- 落地页及第三方监测地址可从公网访问；
- Banner 点击监测需要时已使用 `{CLICK_URL}`；
- 价格和底价使用兼容币种；
- 定向与供应侧流量范围没有互相排斥；
- 修改已进入运行缓存。若页面已保存但行为未变化，请联系运营方检查缓存刷新和运行节点。

## 4. 报表与计量口径

广告主仪表盘和报表可查看近 24 小时数据、主要广告组和主要广告位。数据由日志聚合与账务定时任务生成，因此不是请求级实时数据。

当前常规投放口径如下：

- 展示：有效 `/imp` 跟踪到达后计入；
- 点击：有效 `/clk` 跟踪到达后计入；
- 花费：以展示跟踪记录中的已服务 USD eCPM 为基础；
- Win/Loss：用于分析，不单独作为当前账务花费依据；
- 未触发展示像素的已赢竞价，不会仅凭 win 回调计入常规展示花费。

系统会尽力抑制重复的有效展示和点击事件。共享状态服务暂时不可用时，平台仍优先接收签名有效的测量事件，因此短时间内可能出现重复计量；遇到明显异常时，请向运营方提供发生时间、广告活动、广告组和广告素材信息。

## 5. 外部 DSP / ADX 需求方接入与竞价

如果广告主还经营可接收 OpenRTB 请求的外部 DSP，可以在“竞价端点”中维护自有端点：

```text
/goto/adv/g/bidder?action=topics
```

广告主可编辑：

- 端点名称；
- HTTPS/HTTP 端点 URL；
- OpenRTB 版本；
- Seat；
- 超时时间。

凭据状态和启用状态对广告主可见，但以下内容由平台运营方管理：

- 端点身份凭据、审批和启用；
- 参与竞价的流量方、流量源和广告位范围；
- 路由、超时和加价规则；
- 报表归属与结算配置。

请通过约定的安全渠道向运营方提供接入凭据，不要将密钥写入端点名称、URL 或其他普通表单字段。

审批后，外部需求方有两种可能的触发方式：

- `Fallback`：仅在本地广告无法填充时请求外部端点；
- `Always`：在平台总开关和 Always 独立开关都启用时，也可与本地广告竞争，最终按可比较的有效 CPM 选择赢家。

端点还必须通过自身对应的合成广告组流量范围检查，才会收到相关流量方、网站/App 或广告位的请求。路由成员关系不代表无条件获得全部流量。

外部 DSP 应注意：

- 平台转发完整的原始 OpenRTB 请求形状，并覆盖 `ext.request_domain`；
- 迟到、非法、低于底价或非 USD 的响应会被丢弃；
- 平台保留下游广告代码，但用平台签名的 `/mid/*` 地址代理 win、loss 和 bill 回调；
- `burl` 优先作为可计费事件；没有 `burl` 时，win 才是计费回退；
- 合作式点击通知地址位于 `ext.aofei_middleman.click_notify_urls`，下游素材需要主动接入；平台不改写任意 `adm`；
- 广告主报表按外部 DSP 应付侧花费展示；平台结算口径由运营方另行说明。

新增或修改端点后，应等待运营方完成审批、凭据和流量路由配置，再进行流量测试。

## 6. 常见问题

### 有素材但没有竞价

检查上层对象是否启用、时间和预算是否有效、尺寸是否匹配、底价币种是否为 USD，以及定向、行业与供应侧流量范围是否过窄。若刚修改配置，联系运营方确认缓存已发布。

### 有 win 但报表没有展示或花费

当前账务以展示跟踪为准，而不是只看 win。检查素材中的展示像素是否被客户端加载，并确认报表处理时间是否已经覆盖对应测试时段。

### Banner 有展示但没有点击

确认素材明确使用 `{CLICK_URL}`。系统不会自动包装任意 iframe 内部链接。

### 上传人群导致投放明显减少

确认请求能提供全部已配置标识类型，且值已存在于广告主上传集合。上传人群命中具有优先层级，配置时应避免意外排除其他候选广告组。

### 竞价端点显示已保存但没有流量

保存端点信息不等于已经启用。请运营方检查端点审批、身份凭据、流量范围、路由状态和平台功能开关。
