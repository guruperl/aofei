# Prompt V22

Make W8M marketplace analytics and controlled experimentation a concrete,
privacy-bounded product contract rather than a collection of legacy ledger
views.

- derive scoped advertiser, publisher, and operator interval facts with fixed
  UTC/USD/source/freshness semantics;
- preserve route/commercial dimensions in authorized storage rather than
  dynamic runtime metrics;
- add deterministic observational experiments with explicit lifecycle,
  exposure, declared outcomes, retention, and erasure;
- expose authenticated report/UI exports without treating internal Summer JSON
  as a public API; and
- retain MySQL until measured production query/retention/volume triggers justify
  a different analytical store.
