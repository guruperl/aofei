### 1. **竞价请求 ID (`id`)**  
   - `"id": "cf7eb49e37bc47a742aedba823b386c7"`  
   - 这是广告竞价请求的唯一标识符。

### 2. **竞价响应内容 (`seatbid`)**  
   - 包含竞价成功的广告信息，`seatbid`数组中有一个竞价席位。  

#### 2.1 **广告投放信息 (`bid`)**  
   - `"id": "206101F2BDFAA998E49C8A1736911100146"`  
     - 竞价成功的广告唯一标识符。  
   - `"impid": "814f5bd2581840d7bc18863f3bca0f3e"`  
     - 竞价请求中对应的广告展示位 ID。  
   - `"price": 0.475`  
     - 该广告的竞得价格，单位为美元（USD）。  
   - `"nurl"`  
     - 广告成功展示时的通知 URL，其中 `${AUCTION_PRICE}` 等变量会在请求时替换。  
   - `"lurl"`  
     - 广告竞价失败时的通知 URL。  

#### 2.2 **广告创意 (`adm`)**  
广告素材的 JSON 数据，包含：  
   - `"title": "KION – фильмы, сериалы и тв"`  
     - 广告的标题，表示推广 KION 平台的电影、电视剧和电视内容。  
   - `"img"`  
     - 广告图片链接，尺寸为 64x64 像素。  
   - `"link"`  
     - 点击广告后的跳转链接。  
   - `"clicktrackers"`  
     - 点击监测链接数组，确保不同渠道都可以记录广告点击情况。  
   - `"imptrackers"`  
     - 展示监测链接数组，记录广告的曝光情况。  
   - `"fallback"`  
     - 如果无法打开广告落地页，用户将跳转到 Google Play 应用商店，推广的应用为 `ru.mts.mtstv`。

### 3. **广告元信息**  
   - `"adid": "89941"` → 广告 ID  
   - `"bundle": "ru.mts.mtstv"` → 目标应用的包名（用于移动广告）  
   - `"iurl"` → 广告图片的 URL  
   - `"cid": "4198"` → 该广告活动的 Campaign ID  
   - `"crid": "89941"` → 创意 ID  
   - `"cat": ["IAB1"]` → 广告类别（IAB1 表示艺术和娱乐类）  
   - `"w": 64, "h": 64` → 广告的宽高（像素）  
   - `"exp": 14400` → 广告的有效期（秒）  

### 4. **其他竞价信息**  
   - `"seat": "1_184"` → 代表广告投放席位 ID  
   - `"group": 0` → 表示此竞价是否属于一个捆绑投放（0 代表独立投放）  

### 5. **全局竞价信息**  
   - `"bidid": "206101F2BDFAA998E49C8A1736911100146"` → 竞价请求的 ID，供 DSP 追踪  
   - `"cur": "USD"` → 货币单位为美元  
   - `"customdata": ""` → 额外自定义数据字段（此处为空）  

### 6. **扩展字段 (`ext`)**  
   - `"adtype": 2` → 广告类型（例如 2 代表原生广告）  
   - `"request_domain": "exchange.example.test"` → 发起竞价请求的域名  
   - `"x-openrtb-version": "2.5"` → 使用的 OpenRTB 版本
